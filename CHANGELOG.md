# Changelog

Skybridge is released via [goreleaser](./.goreleaser.yaml) on every tag push, and GitHub
auto-generates per-release notes from commit history. See
[Releases](https://github.com/curlix-io/skybridge/releases) for the authoritative, per-version
changelog rather than a hand-maintained duplicate here.

For unreleased work, see commits on `main` since the latest tag.
